# Thémis（テミス）

予備試験・司法試験の学習アプリです。ブラウザだけで動き、サーバーは要りません。

## 収録内容

- 入門編（科目ごとの読み物）
- 一問一答
- 論点集（論証カード）
- 短答式の過去問（司法試験・予備試験、平成〜令和）。解説と引用条文つきです。
- 論文式の過去問（問題・出題の趣旨・論点整理・答案例）
- 予想問題（短答・論文）
- 六法（e-Gov 法令データ）

## 使い方

`index.html` を開くと起動します。`data` フォルダは、必ず `index.html` と同じ場所に置いてください。

GitHub Pages を有効にすると、スマホからもURLで開けます（Settings → Pages → Branch: main / root）。

学習記録は、開いたブラウザの中（キー `lawq-state-v1`）に保存されます。

## 注意

- 解説・答案例・論点整理は学習用に作成したもので、唯一の正解ではありません。判例の要約は原典と照合していないものを含みます。
- 過去問の問題文と出題の趣旨は、法務省の公表資料によります。
- 論証カードは、オリジナルへの書き直しが済んだものから順に収録しています。
